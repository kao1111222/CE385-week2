${nickname}, ${age} และตัวแปรอื่น ๆ ใช้สำหรับ นำค่าจากตัวแปรมาแทรกในข้อความ

  ex2-types

สร้างตัวแปรให้ครบ 6 ชนิดข้อมูล ได้แก่ string, number, boolean, undefined, null และ array
string ใช้เก็บข้อความ เช่น "สวัสดีครับ"
number ใช้เก็บตัวเลข เช่น 191
boolean ใช้เก็บค่าจริงหรือเท็จ เช่น true
undefined คือ ตัวแปรที่ประกาศไว้แต่ ยังไม่ได้กำหนดค่า
null ใช้แทนค่าที่ตั้งใจให้เป็น ค่าว่าง
array ใช้เก็บข้อมูลหลายค่าไว้ในตัวแปรเดียว เช่น [4, 5, 6]
ใช้ typeof เพื่อตรวจสอบว่า ข้อมูลแต่ละตัวเป็นชนิดอะไร แล้วนำผลไปแสดงใน Console
typeof null จะได้ "object" แม้ว่าตามความหมายจริง null จะเป็นค่าว่าง ซึ่งเป็นพฤติกรรมเก่าใน JavaScript
Number("abc") จะได้ NaN และ typeof NaN จะได้ "number" เพราะ NaN เป็นค่าพิเศษที่อยู่ในชนิด Number
Number.isNaN() ใช้ตรวจสอบว่าค่าที่ได้เป็น NaN จริงหรือไม่
Number(inputAge) ใช้แปลง "20" จาก String เป็น Number จึงสามารถนำไปบวก 5 และได้ 25
.toFixed(1) ใช้กำหนดให้คะแนนแสดง ทศนิยม 1 ตำแหน่ง เช่น 85.5
inputAge === 20 ได้ false เพราะ "20" เป็น String แต่ 20 เป็น Number
Number(inputAge) === 20 ได้ true เพราะแปลง "20" ให้เป็น Number ก่อนเปรียบเทียบ

  ex4-grade
สร้างฟังก์ชัน toGrade(score) เพื่อรับคะแนนเข้ามา แล้วนำคะแนนไป ตรวจสอบและตัดเกรด
ก่อนตัดเกรด มีการตรวจสอบว่าคะแนนอยู่ระหว่าง 0–100 หรือไม่ ถ้าต่ำกว่า 0 หรือมากกว่า 100 จะแสดงว่า คะแนนไม่ถูกต้อง และใช้ return เพื่อหยุดการทำงานทันที
ใช้ if / else if / else ในการตัดเกรดตามช่วงคะแนน เช่น 80 ขึ้นไปได้ A, 75 ขึ้นไปได้ B+ และไล่ลงมาตามเกณฑ์
ต้องเรียงเงื่อนไขจาก คะแนนมากไปน้อย เพราะโปรแกรมจะตรวจจากบนลงล่าง เมื่อเจอเงื่อนไขที่เป็นจริงแล้ว จะไม่ตรวจเงื่อนไขถัดไป
ตัวแปร grade ใช้เก็บ เกรดที่ได้ ก่อนนำไปแสดงผล
console.log() ใช้แสดงผลคะแนนและเกรด เช่น คะแนน 78 -> B+
testScores เป็น Array ที่เก็บคะแนนสำหรับทดสอบทั้งหมด 13 ค่า รวมทั้งคะแนนปกติและคะแนนผิด เช่น -5 กับ 120
ใช้ for...of เพื่อวนดูคะแนนใน Array ทีละตัว แล้วส่งคะแนนเข้าไปในฟังก์ชัน toGrade(score) ทำให้ไม่ต้องเขียนคำสั่งซ้ำ 13 รอบ
ใส่ { } ครบทุกเงื่อนไขตามที่โจทย์กำหนด

  ex5-switch

สร้างฟังก์ชัน getMenuPrice(menu) เพื่อใช้ switch ตรวจชื่อเมนูและ คืนราคาของอาหาร
เมนูที่ราคา 50 บาท ได้แก่ ข้าวผัด ข้าวมันไก่ และข้าวหมูแดง จึงใช้ fall-through โดยรวม case ทั้ง 3 อันไว้ด้วยกัน แล้วให้ return 50 ครั้งเดียว เพื่อลดการเขียนโค้ดซ้ำ
เมนูผัดไทยได้ 60 บาท และต้มยำกุ้งได้ 120 บาท
default: return 0 ใช้กรณีที่สั่งเมนูที่ไม่มีในรายการ เช่น ตำปลาร้า เพื่อให้ราคาเป็น 0 และเป็นการทดสอบ default
ฟังก์ชัน getSizeMultiplier(size) ใช้ switch กำหนด ตัวคูณตามขนาดอาหาร โดยธรรมดา = 1, พิเศษ = 1.5 และขนาดใหญ่สุด = 2
default ของฟังก์ชันขนาดกำหนดเป็น 1 เพื่อให้ถ้าใส่ขนาดที่ไม่มีในรายการ ก็ยังสามารถคำนวณราคาได้
orders เป็น Array ของออร์เดอร์ แต่ละรายการมี menu = ชื่ออาหาร, size = ขนาด และ qty = จำนวนที่สั่ง
ใช้ for...of เพื่อวนอ่านออร์เดอร์ทีละรายการ แล้วนำข้อมูลไปคำนวณราคา
basePrice เก็บราคาอาหาร และ multiplier เก็บตัวคูณของขนาด
itemTotal คำนวณด้วยสูตร ราคาเมนู × ตัวคูณขนาด × จำนวน
totalBill ใช้เก็บ ยอดรวมทั้งหมดของทุกออร์เดอร์ โดยนำราคาของแต่ละรายการมาบวกสะสม
ใช้ console.log() และ Template Literal เพื่อแสดงผล เช่น ผัดไทย (พิเศษ) x 4 = 360 บาท
ผัดไทย (พิเศษ) × 4 = 60 × 1.5 × 4 = 360
ข้าวผัด (ธรรมดา) × 4 = 50 × 1 × 4 = 200
ต้มยำกุ้ง (โคตรพิเศษ) × 2 = 120 × 2 × 2 = 480
ข้าวหมูแดง (พิเศษ) × 1 = 50 × 1.5 × 1 = 75
ตำปลาร้า (พิเศษ) × 1 = 0 × 1.5 × 1 = 0
ดังนั้นรวมจริงคือ 1,115 บาท ครับ

  ex6-login

สร้างฟังก์ชัน login(inputUser, inputPass, role, isActive, age) เพื่อรับข้อมูล ชื่อผู้ใช้, รหัสผ่าน, สิทธิ์, สถานะบัญชี และอายุ แล้วตรวจสอบการเข้าสู่ระบบ
ตรวจสอบ username และ password เป็นอันดับแรก โดยใช้ || และ !== ถ้าผิดอย่างใดอย่างหนึ่งจะ return ทันทีว่า ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง
จากนั้นตรวจสอบ isActive === false เพื่อดูว่าบัญชีถูกระงับหรือไม่ ถ้าถูกระงับจะไม่สามารถเข้าสู่ระบบได้
ต่อมาตรวจสอบ age < 18 เพื่อดูว่าผู้ใช้มีอายุถึงเกณฑ์หรือไม่ ถ้าไม่ถึงจะ return "อายุไม่ถึงเกณฑ์"
หลังจากผ่านการตรวจสอบทั้งหมดแล้ว จึงตรวจสอบ role ว่าเป็น อาจารย์ หรือนักศึกษา เพื่อกำหนดสิทธิ์ในการใช้งาน
ถ้าเป็น "อาจารย์" จะได้สิทธิ์ ผู้ดูแล ส่วน "นักศึกษา" จะได้สิทธิ์ ทั่วไป
มี else รองรับกรณีที่ role ไม่ตรงกับข้อมูลที่กำหนด เพื่อไม่ให้ระบบรับสิทธิ์ที่ไม่ถูกต้อง
ใช้ return ภายในฟังก์ชันแทน console.log() ทำให้ฟังก์ชันมีหน้าที่ ตรวจสอบและส่งผลลัพธ์กลับมา ส่วน console.log() ทำหน้าที่แสดงผลตอนเรียกใช้ฟังก์ชัน
ใช้ === / !== ตามเงื่อนไข และมีทั้ง || และ && ตามแนวคิดการตรวจสอบเงื่อนไข
สร้างการทดสอบ 6 กรณี ได้แก่ อาจารย์สำเร็จ, นักศึกษาสำเร็จ, รหัสผ่านผิด, ชื่อผู้ใช้ผิด, บัญชีถูกระงับ และอายุไม่ถึงเกณฑ์
